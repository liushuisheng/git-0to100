GitHub Pages Ready

无需构建工具，直接发布到 GitHub Pages

本项目采用纯静态 HTML、CSS、JavaScript。推送到 GitHub 后，在仓库 Settings → Pages 中选择当前分支和根目录即可访问。

  1. 提交并推送当前分支。
  2. 打开 GitHub 仓库 Settings → Pages。
  3. Source 选择 Deploy from a branch。
  4. Branch 选择当前分支，Folder 选择 /root。
